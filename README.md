# FindIt 🔍
### A Community-Driven College Lost & Found Web Portal

FindIt is a responsive, frontend web application that helps college students and staff report, search, and reclaim lost belongings through a clean and interactive portal — all without any external backend dependency.

---

## ✨ Features

- **User Authentication** — Sign up and sign in with persistent local session management
- **Report Lost Items** — Submit detailed lost item reports with date, location, and description
- **Report Found Items** — Upload found items with mandatory image proof for credibility
- **Smart Search** — Instantly search through all unidentified items by keyword
- **Item Claiming System** — Claim found items and get direct finder contact details to verify ownership
- **Resolution Confirmation** — Mark items as successfully returned with a celebratory confetti animation 🎉
- **Karma Points System** — Earn reward points for every found item you report, encouraging community participation
- **User Profile Dashboard** — View all your lost and found reports in one place with tabs
- **Responsive UI** — Clean, mobile-friendly design built with pure HTML, CSS, and JavaScript

---

## 🛠️ Built With

- **HTML5** — Semantic structure and layout
- **CSS3** — Custom properties, animations, and responsive grid/flexbox
- **Vanilla JavaScript (ES6)** — DOM manipulation, local storage, and state management

---

## 📸 How It Works

1. **Sign Up / Sign In** — Create your college account with name, ID, phone, and email
2. **Report Lost** — Fill in item details and submit a lost report
3. **Report Found** — Upload an image and describe the found item
4. **Browse & Search** — Search unidentified items to find your lost belonging
5. **Claim & Resolve** — Claim your item, contact the finder, and confirm receipt
6. **Earn Karma** — Get karma points for helping others find their belongings

---

## 💡 Key Highlights

- **Zero Backend** — Fully frontend; all data managed via Browser LocalStorage
- **Image Validation** — Found item reports require an image upload for authenticity
- **Time Tracking** — Every report shows relative time (e.g., "2 hours ago")
- **Gamified Experience** — Karma point system to motivate community participation
- **Smooth UX** — Fade animations, hover effects, and confetti celebration on item resolution
